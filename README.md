### About

I've spent the last few years building full-stack applications with TypeScript —
REST APIs, authentication and role-based access control, background jobs, file
handling, and the database design underneath all of it. Lately a lot of that work
involves integrating LLMs into real products: retrieval pipelines, document
parsing, and the unglamorous plumbing that makes them reliable.

I also take on freelance and client work, and I'm open to collaborating on
interesting problems.
